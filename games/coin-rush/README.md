# Coin Rush

Top-down WASD coin collector prototype built with s&box.

- `Code/Player.cs` — WASD movement on XY plane, `Score` property.
- `Code/Coin.cs` — Trigger pickup that increments player score and self-destructs.
- `Code/UI/ScoreHud.razor` — HUD displaying current score with a Material Icons glyph.
- `Assets/scenes/main.scene` — Generated from `main.scene.gen.py`.
